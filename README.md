# 🍳 Mood Recipe Recommender

A simple, beautiful web app that recommends recipes based on your current mood! Select a mood, get a recipe, and if you don't like it, just click for a new one.

## Features

- 🎭 8 different moods to choose from
- 🍽️ Multiple recipe options per mood
- 🔄 Easy recipe switching with one click
- 📱 Responsive design that works on all devices
- 🎨 Beautiful, modern UI

## Technologies Used

- **HTML5** - Structure
- **CSS3** - Styling with modern gradients and animations
- **Vanilla JavaScript** - No frameworks, pure and simple

## Why Vanilla JavaScript?

I chose vanilla HTML/CSS/JavaScript for this project because:
- ✅ **Simple** - No build process or dependencies
- ✅ **Fast** - No framework overhead
- ✅ **Easy to deploy** - Works perfectly with GitHub Pages
- ✅ **Easy to understand** - Straightforward code that's easy to modify
- ✅ **No maintenance** - No package updates or security vulnerabilities

## Getting Started

1. Clone this repository or download the files
2. Open `index.html` in your web browser
3. That's it! No installation needed.

## Deployment to GitHub Pages

Deploying to GitHub Pages is incredibly simple:

1. **Create a GitHub repository** (if you haven't already)
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/yourusername/your-repo-name.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your repository on GitHub
   - Click on **Settings**
   - Scroll down to **Pages** in the left sidebar
   - Under **Source**, select **main** branch (or **master** if that's your default)
   - Click **Save**

3. **Your app will be live at**:
   ```
   https://yourusername.github.io/your-repo-name/
   ```

That's it! Your app will be live in just a few minutes.

## Customization

Want to add more recipes or moods? It's easy!

- **Add recipes**: Edit the `recipes` object in `script.js`
- **Add moods**: Add a new mood button in `index.html` and add corresponding recipes in `script.js`
- **Change styling**: Modify `styles.css` to match your preferences
